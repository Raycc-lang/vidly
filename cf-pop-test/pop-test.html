🔍 How to read the result

If PoP = RUH or JED: Cloudflare routes your traffic through a Saudi PoP. If the local bucket decreased → IP routing works. If only the international bucket decreased → carrier is doing app-level DPI classification (bypasses IP routing).

If PoP is outside SA: Saudi carrier is not routing Cloudflare anycast locally. Cloudflare Calls will consume international data.

Test total: 20 MB. If your carrier billing rounds in 100 KB increments, this is easily measurable. If your data plan has very large buckets, you may need multiple runs.
